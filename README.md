## About the Project

**JavaScript Practice Projects** is a front-end web design repository created to practice real-world DOM manipulation, responsive layouts, UI component building, and modern JavaScript logic.

The project represents a collection of interactive web tools. It presents these tools in a clean and attractive way by using smooth typography, glassmorphism effects, dynamic data rendering, and responsive grid/flexbox layouts.

This project is suitable for a portfolio because it demonstrates real-world frontend skills such as HTML structure, Tailwind CSS styling, responsive CSS, JavaScript array methods, and real-time state management.

Projects Included
1. User Finder
A responsive directory interface that allows users to search through profiles in real-time. It dynamically generates user profile cards (complete with images and bios) and handles empty states ("User Not Found") using JavaScript array methods and DOM manipulation. The layout utilizes Tailwind CSS and Flexbox to ensure cards wrap perfectly on any screen size.

2. Theme Changer
An interactive web component demonstrating state management. It intercepts user clicks to toggle visual CSS themes dynamically across the user interface, changing the overall look and feel instantly without reloading the page.

3. Practice Sandbox
A dedicated workspace containing standard HTML, CSS, and JS files. This section is used for testing new core logic, algorithms, and general web development concepts before integrating them into larger projects.

Responsive Design

Responsiveness is handled primarily using Tailwind CSS, custom CSS Flexbox (flex-wrap, justify-center), and min-height properties. The layout automatically adjusts cards, spacing, and text sizes to maintain a clean user experience across all devices.

How to Run the Project
This is a static frontend project, so you do not need to install any packages or run a backend server.

Option 1: Open Directly in Browser
Download or clone the repository.

Open the project folder and navigate to a specific project (e.g., Projects/user Finder).

Double-click the index.html file.

The project will open in your browser.

Option 2: Run with VS Code Live Server
Open the project folder in Visual Studio Code.

Install the Live Server extension.

Right-click on the index.html file of the project you want to view.

Select Open with Live Server.

The project will run locally in your browser.
