## About the Project

**JavaScript Practice Projects** is a front-end web design repository developed to practice real-world DOM manipulation, array filtering, responsive layouts, custom styling, and Tailwind CSS utility usage.

The goal of this project is to create visually attractive, interactive, and easy-to-use web applications that function flawlessly on desktop, tablet, and mobile screens.

## Features

- Modern and clean user interfaces
- Fully responsive layouts using Flexbox and Tailwind CSS
- Real-time search and filtering functionality 
- Dynamic DOM element creation and rendering
- Graceful error handling (e.g., "User Not Found" states)
- Interactive theme toggling and state management
- Glassmorphism effects and custom CSS styling
- Organized multi-project folder structure

## Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Page structure and semantic content |
| CSS3 | Custom animations, hover effects, and glassmorphism styling |
| Tailwind CSS | Rapid UI development, utility classes, and responsive design |
| JavaScript (ES6+) | Core application logic, array methods, and DOM manipulation |
| Web Fonts | Typography styling |

## Projects Included

### 1. User Finder

A responsive directory interface that allows users to search through profiles in real-time. It dynamically generates user cards and handles empty states using JavaScript array methods and DOM manipulation.

### 2. Theme Changer

An interactive web component demonstrating state management by intercepting user clicks to toggle visual themes dynamically across the UI.

### 3. Practice Sandbox

A dedicated workspace containing standard HTML, CSS, and JS files for testing new algorithms and UI components.

## How to Run the Project

This is a static front-end project, so no installation is required.

### Option 1: Open Directly

1. Download or clone the repository.
2. Open the specific project folder you wish to view (e.g., `Projects/user Finder`).
3. Double-click `index.html` to open it in your browser.

### Option 2: Run with VS Code Live Server

1. Open the project in VS Code.
2. Install the **Live Server** extension.
3. Right-click on `index.html`.
4. Click **Open with Live Server**.
